Фото для карты лежат по папкам городов:
  ekb/     — Екатеринбург
  moscow/  — Москва
  spb/     — Санкт-Петербург

Имена файлов должны совпадать со списками photos в js/config.js
(например assets/photos/ekb/eltsin-1.jpg). Фото на одно место можно добавить сколько угодно:
просто допиши путь в его список photos. Все фото города показываются галереей под картой,
по нажатию открываются на весь экран.

Совет: сожми фото до ~1200px по длинной стороне (например, squoosh.app), чтобы сайт грузился быстро.
