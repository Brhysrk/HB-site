# Сайт-открытка для Дианы 🌸

Домен: **diana-ich-liebe-dich.ru**

## Структура
```
index.html        — все экраны
css/style.css     — оформление (пастель, «музейные рамы»)
js/config.js      — ВСЕ тексты и настройки: пароль, фразы, комплименты, места, плейлист, письмо
js/main.js        — логика
assets/photos/    — фото для карты
assets/music/     — mp3 для плейлиста и вальса (never-enough.mp3)
CNAME             — домен для GitHub Pages
```

## Разделы (в порядке показа)
0. Таймер до дня рождения: до 12.11 00:00 по времени Австрии вместо открытки идёт обратный отсчёт (`openAt` в `js/config.js`), потом сайт открывается сам
1. Пароль (по умолчанию `101`) с забавными фразами за неправильные попытки, после 3-й появляется подсказка
2. «Вам был отправлен подарок»: «Принять» / убегающее «Отклонить»
3. С днём рождения: конфетти, падающие розы и сырки, торт со свечами (нажатие или задувание в микрофон), желание
4. Окно «Я приготовил для тебя несколько подарков!»
5. Генератор комплиментов
6. Мой плейлист + кнопка «Слушать на Яндекс Музыке»
7. Окно «Я всё помню» (`rememberText`, `rememberSmall`)
8. Карта фоток: сердечки на местах, по нажатию открывается альбом фото этого места, сердечко-загадка в Вене «To be continued...»
9. Окно «Все эти подарки в цифровом формате...»
10. «Чай? Кофе? …» → ответ «Потанцуем» → вальс под Never Enough
11. Личное письмо в конверте
12. Отзыв: сердечки и пара слов, «Отправить» сохраняет их в Google Таблицу (`feedbackEndpoint`), а без неё открывает `feedbackLink` или «Поделиться» на телефоне (тексты `feedback…`)

Порядок выбран по нарастанию удивления. Поменять его можно атрибутами `data-next` у кнопок «Дальше» в `index.html` и списком `NAV` в начале `js/main.js`.

Карте не нужен API-ключ: она на Leaflet с бесплатными тайлами OpenStreetMap/CARTO.

## Как посмотреть локально
Открой `index.html` двойным кликом. Чтобы пропустить пароль и подарок при отладке, добавь в конце адреса `#dev`.
Пока идёт таймер, сначала пропусти его: 5 раз быстро нажми на 🎁 и введи код `timerDebugCode` из `js/config.js` (запоминается на этом устройстве). Чтобы снова увидеть таймер, добавь в конце адреса `#timer`.
Микрофон в браузере работает только по https или на localhost, поэтому для теста задувания запусти:
`python -m http.server 8000` и открой http://localhost:8000

## Что заполнить
- Тексты, пароль, комплименты, письмо — в `js/config.js`
- Фото в `assets/photos/`, музыку в `assets/music/` (см. README.txt внутри)

## Отзывы в Google Таблицу
Оценка и текст из последнего окна сохраняются строкой в Google Таблицу. Настраивается один раз, минут за пять:
1. Создай таблицу на https://sheets.new (например, «Отзыв Дианы»).
2. В таблице: Расширения → Apps Script. Удали всё в редакторе, вставь содержимое `tools/feedback-sheet.gs` и сохрани (💾).
3. Справа сверху: Начать развертывание → Новое развертывание → шестерёнка «Выберите тип» → Веб-приложение.
   Запуск от имени: «Я», доступ: «Все». Нажми «Начать развертывание».
4. Google попросит разрешение: Предоставить доступ → свой аккаунт → «Дополнительные настройки» → «Перейти на страницу проекта» → Разрешить.
   Предупреждение «приложение не проверено» нормальное: это твой собственный скрипт.
5. Скопируй «URL веб-приложения» (`https://script.google.com/macros/s/…/exec`) и вставь его в `feedbackEndpoint` в `js/config.js`.
   Проверка: открой этот адрес в браузере, должно быть написано `ok`.

Если позже поменяешь скрипт, нужно Начать развертывание → Управление развертываниями → ✏️ → Версия: новая → Развернуть, иначе работает старая версия. Адрес при этом не меняется.
Адрес виден в публичном репозитории, поэтому теоретически писать в таблицу может кто угодно; читать её может только владелец.

## Публикация на домене
Вариант A, GitHub Pages (бесплатно, https автоматически):
1. Залей папку в репозиторий на GitHub, включи Settings → Pages → ветка `main`.
2. Файл `CNAME` уже лежит в корне.
3. У регистратора домена добавь DNS-записи: A на `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` и CNAME `www` → `<логин>.github.io`.
4. В настройках Pages включи «Enforce HTTPS».

Вариант B, хостинг у регистратора (Beget, SpaceWeb и т.п.): просто загрузи содержимое папки в `public_html`.
