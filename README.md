# Сайт-открытка для Дианы 🌸

Домен: **diana-ich-liebe-dich.ru**

## Структура
```
index.html        — все экраны
css/style.css     — оформление (пастель, «музейные рамы»)
js/config.js      — ВСЕ тексты и настройки: пароль, фразы, комплименты, места, плейлист, письмо
js/main.js        — логика
assets/photos/    — фото для карты
assets/music/     — mp3 для плейлиста и вальса (never-enough.mp3)
CNAME             — домен для GitHub Pages
```

## Разделы (в порядке показа)
1. Пароль (по умолчанию `101`) с забавными фразами за неправильные попытки, после 3-й появляется подсказка
2. «Вам был отправлен подарок»: «Принять» / убегающее «Отклонить»
3. С днём рождения: конфетти, падающие розы и сырки, торт со свечами (нажатие или задувание в микрофон), желание
4. Окно «Я приготовил для тебя несколько подарков!»
5. Генератор комплиментов
6. Мой плейлист + кнопка «Слушать на Яндекс Музыке»
7. Карта фоток: сердечки на местах, по нажатию открывается альбом фото этого места, сердечко-загадка в Вене «To be continued...»
8. Окно «Все эти подарки в цифровом формате...»
9. «Чай? Кофе? …» → ответ «Потанцуем» → вальс под Never Enough
10. Личное письмо в конверте

Порядок выбран по нарастанию удивления. Поменять его можно атрибутами `data-next` у кнопок «Дальше» в `index.html` и списком `NAV` в начале `js/main.js`.

Карте не нужен API-ключ: она на Leaflet с бесплатными тайлами OpenStreetMap/CARTO.

## Как посмотреть локально
Открой `index.html` двойным кликом. Чтобы пропустить пароль и подарок при отладке, добавь в конце адреса `#dev`.
Микрофон в браузере работает только по https или на localhost, поэтому для теста задувания запусти:
`python -m http.server 8000` и открой http://localhost:8000

## Что заполнить
- Тексты, пароль, комплименты, письмо — в `js/config.js`
- Фото в `assets/photos/`, музыку в `assets/music/` (см. README.txt внутри)

## Публикация на домене
Вариант A, GitHub Pages (бесплатно, https автоматически):
1. Залей папку в репозиторий на GitHub, включи Settings → Pages → ветка `main`.
2. Файл `CNAME` уже лежит в корне.
3. У регистратора домена добавь DNS-записи: A на `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` и CNAME `www` → `<логин>.github.io`.
4. В настройках Pages включи «Enforce HTTPS».

Вариант B, хостинг у регистратора (Beget, SpaceWeb и т.п.): просто загрузи содержимое папки в `public_html`.
